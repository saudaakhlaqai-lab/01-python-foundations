# Project 19 – Interactive Client Management System

## Objective

Build a menu-driven Python application that allows users to register clients, view client records, save data to a CSV file, and exit the application.

## Skills Learned

- while loops
- break
- Menu-driven programs
- User interaction
- Functions
- Lists
- Dictionaries
- CSV

## Features

- Interactive menu
- Register clients
- View all clients
- Save client records
- Exit application

## Real-World Application

Most desktop applications and internal business tools use menu-driven logic. This project demonstrates how software can remain active, respond to user choices, and perform different tasks without restarting.
