# Project 18 – AI Client Intake Automation

## 📌 Objective

Develop a Python application that collects, validates, stores, displays, and exports client information using structured data.

---

## 🚀 Skills Demonstrated

- Variables
- Functions
- Lists
- Dictionaries
- Loops
- Error Handling
- CSV
- JSON
- Data Validation

---

## 💻 Features

- Register multiple clients
- Validate user input
- Display client records
- Identify minor and adult clients
- Export records to CSV
- Generate JSON output

---

## 🌍 Real-World Application

This project simulates the first stage of an AI-powered client onboarding system.

The same workflow can later integrate with:

- Google Forms
- Google Sheets
- OpenAI API
- Gmail
- HubSpot
- Salesforce
- n8n
- Make.com
