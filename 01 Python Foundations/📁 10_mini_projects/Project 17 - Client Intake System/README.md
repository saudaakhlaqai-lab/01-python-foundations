# Project 17 – Client Intake System

## 📌 Objective

Build a client intake system that collects client information, validates user input, stores structured data, displays client records, and exports them to a CSV file.

---

## 🚀 Skills Learned

- Functions
- Lists
- Dictionaries
- Loops
- Error Handling
- CSV Writing
- User Input
- Data Validation

---

## 💻 Features

- Add new clients
- Validate age input
- Display all clients
- Export client records to CSV
- Store structured client information

---

## 🌍 Real-World Application

This project simulates the first stage of an AI-powered client onboarding workflow.

The same structure can later be extended to:

- Google Forms
- Google Sheets
- HubSpot CRM
- Salesforce
- OpenAI API
- n8n
- Make.com
