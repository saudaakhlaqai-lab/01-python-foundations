# Lab 04 - File Management

## Objective

Create, copy, move, rename, and delete files and folders.

---

## Step 1

Create a directory.

```bash
mkdir projects
```

---

## Step 2

Enter the directory.

```bash
cd projects
```

---

## Step 3

Create a file.

```bash
touch notes.txt
```

---

## Step 4

Display the file.

```bash
cat notes.txt
```

---

## Step 5

Copy the file.

```bash
cp notes.txt notes_backup.txt
```

---

## Step 6

Rename the file.

```bash
mv notes_backup.txt backup.txt
```

---

## Step 7

Delete the copied file.

```bash
rm backup.txt
```

---

## Step 8

Go back one directory.

```bash
cd ..
```

---

## Step 9

Remove the folder.

```bash
rm -r projects
```

---

## Skills Practiced

- mkdir
- touch
- cat
- cp
- mv
- rm
