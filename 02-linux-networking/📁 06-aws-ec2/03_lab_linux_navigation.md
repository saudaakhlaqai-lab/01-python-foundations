# Lab 03 - Linux Navigation

## Objective

Practice navigating the Linux file system.

---

## Step 1

Check your current location.

```bash
pwd
```

Example Output

```text
/home/ec2-user
```

---

## Step 2

List files.

```bash
ls
```

---

## Step 3

List files with details.

```bash
ls -l
```

---

## Step 4

Move into another directory.

```bash
cd /home
```

---

## Step 5

Return to your home directory.

```bash
cd ~
```

---

## Step 6

Clear the terminal.

```bash
clear
```

---

## Skills Practiced

- pwd
- ls
- ls -l
- cd
- clear
